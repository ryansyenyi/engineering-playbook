JWT — JSON Web Token

A signed, self-contained set of claims a recipient can verify without calling back to the issuer. That stateless property is the entire reason to reach for a JWT — and the source of everything hard about revoking one.

authentication ✓ reviewed 2026-09-07 4 sources RFC 7519

When to use

Use a JWT as an access token for service-to-service calls where the verifying party should not need a shared session store. Keep lifetimes short: the token is a bearer credential you cannot take back before it expires. For browser-facing applications, prefer a session cookie.

# verifier configuration — the four checks that matter
algorithms: ["EdDSA"]          # pinned, never "none"
issuer:     "https://auth.internal"
audience:   "orders-api"
max_ttl:    300                   # seconds — short by default
