Principles

Nine commitments. Every module cites the ones it serves; every decision record explains which one it traded away and why.

P·01

Security first.

The secure path is the default path. Anything else is an exception with an owner and an expiry date.

applied in: jwt · auth-checklist · adr-0001
P·02

Least privilege.

Every credential, token, and role carries the minimum it needs. Scope creep is a bug, not a convenience.

applied in: oauth2 · refresh-tokens
P·03

Defense in depth.

No single control is trusted to hold. Each layer assumes the one above it has already failed.

applied in: auth-checklist · secure-headers
P·04

API first.

The contract is designed before the implementation. Breaking a published contract requires a decision record.

applied in: api-design
P·05

Twelve-factor.

Config in the environment, backing services attached, processes stateless. Boring on purpose.

applied in: cloud-native · observability
P·06

Multi-tenant by design.

Tenancy is decided at the schema, not patched at the query. Isolation is provable, not assumed.

applied in: multi-tenancy · database-design
